🧾 Executive Summary สำหรับที่ประชุม EOC

ขั้นตอนเชื่อมต่อ Google Sheets จริง (สรุปย่อ)
  1. สร้าง Google Sheet ตามโครงสร้างคอลัมน์ที่กำหนด แล้วเปิด Google Apps Script
  2. เขียน Web App (doGet) ให้ส่งออกข้อมูลเป็น JSON พร้อม Deploy เป็น "Web App" (Anyone with link)
  3. นำ URL ของ Web App ไปตั้งเป็นแหล่งข้อมูลใน Dashboard เวอร์ชันที่ Host เอง (เช่น Looker Studio ต่อ Sheets โดยตรง หรือเว็บแอปที่ Host บนเซิร์ฟเวอร์ของหน่วยงาน)
  4. ตั้งเวลา Trigger/Auto Refresh ทุก 1–5 นาทีฝั่ง Dashboard ให้ดึงข้อมูลใหม่
  5. หมายเหตุ: หน้านี้เผยแพร่ผ่าน Claude Artifact ซึ่งมีข้อจำกัดด้านความปลอดภัยไม่อนุญาตให้ดึง API ภายนอกโดยตรง จึงต้อง Host เวอร์ชัน Production แยกต่างหาก (Looker Studio / Power BI / เว็บแอปของหน่วยงาน) จึงจะ Auto Refresh จาก Google Sheets ได้จริง
ระบบเฝ้าระวังค่าดัชนีลูกน้ำยุงลาย อำเภอท่าแพ จังหวัดสตูล — ข้อมูลในหน้านี้เป็นข้อมูลสาธิตเพื่อสาธิตการออกแบบ Dashboard เท่านั้น
